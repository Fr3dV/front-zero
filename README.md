# Front Zéro 3D

Jeu de tir militaire en 3D jouable dans le navigateur (three.js r128, aucune étape de build).

Site : https://fz.gamzu.fr

## Contenu
- `index.html` : le jeu complet
- `three.min.js` : moteur 3D three.js r128 (licence MIT, voir `LICENSE-three.txt`)
- `CNAME` : domaine personnalisé pour GitHub Pages
- `.nojekyll` : sert les fichiers tels quels, sans traitement Jekyll

## Mise à jour
Remplacer `index.html` puis pousser sur la branche `main` : GitHub Pages republie en une à deux minutes.
